ADB Setup

First-time USB setup steps.

1. Enable Developer Options on Android: Settings → About → tap Build Number 7×
2. Enable USB Debugging in Developer Options
3. Connect via USB & tap "Allow" on the ADB authorization prompt
4. Click Scan above — device should appear with a "Connected" badge
